# Lab 1 – Flooring Calculator

## Overview
This Python program calculates the cost of flooring for a room based on user input. It determines the room's square footage, flooring cost, 7% sales tax, and the total amount due.

## Features
- Accepts room length and width as input.
- Calculates total square footage.
- Computes flooring cost based on cost per square foot.
- Calculates 7% sales tax.
- Displays the final total cost.

## Skills Demonstrated
- Python
- Variables
- User Input
- Arithmetic Operations
- Problem Solving

## How to Run
1. Run flooring_calculator.py.
2. Enter:
   - Room length
   - Room width
   - Cost per square foot
3. View the calculated results in the terminal.
